# rtx5080-hk-data

Public price data for the page https://rtx5080-hk.netlify.app — the 10 cheapest brand-new RTX 5080 cards
sold by Amazon that ship to Hong Kong, with matching Hong Kong shop prices.

- `data.json` — everything the page renders (cards, Amazon landed HKD price and breakdown, HK shop match/price/link,
  比香港平／貴 difference, data timestamps). Updated automatically after each price-monitor scan.
- `img/<ASIN>.jpg` — product images (from the Amazon product pages).

Prices are approximate and change often; always check the shop / Amazon checkout.
